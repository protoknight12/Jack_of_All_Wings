# PAC-3 MSE missile

- Model: `model/pac-3-mse.glb`, assembled from the 4 STL print files in `source/`. Meters, 5.2 m long, nose toward +X, centered on its midpoint.
- Source STLs are a 3D-print kit (body sections, fins, ACM ring, seeker nose, display stand). Assembly order was inferred from matching diameters/taper, not from official docs:
  tail -> D120 (gray motor), A98 (black motor), EF (gray, 2 shells), C28 (black), ACM ring (silver, thruster holes), B50 (black taper), nose (gray).
- 4 tail fins + 4 long strakes (X layout) were placed by hand. A hidden core cylinder fills the hollow gap in the EF/C sections.
- Left out: the display stand and ~17 tiny print parts (pegs/clips/rectangular bars) that don't visibly belong to the missile.
- Colors in the GLB are flat PBR materials (no textures).
