# F-117 Nighthawk

- Model: `model/nighthawk.obj` + `nighthawk.mtl` (OBJ exported in centimeters; scale to metres in code, x0.01).
- Materials: `UDIM1SG` and `UDIM2SG`. The .mtl has NO texture references, so textures must be assigned in code.
- Textures: PBR maps, two UDIM tiles (1001, 1002): Base_Color, Metallic, Mixed_AO, Normal_OpenGL, Roughness. Large (up to ~10 MB each), consider downscaling for the game.
- Source: `source/nighthawk.zip` is the original download. Never edit it.
